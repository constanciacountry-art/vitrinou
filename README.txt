VITRINOU — versão inicial

1. Abra admin.html no navegador.
2. Senha inicial: 123456.
3. Configure seu WhatsApp com DDI e DDD, somente números (ex.: 5598999999999).
4. Cadastre produtos com foto por URL, preço, categoria e status.
5. Abra index.html para ver o catálogo.

PUBLICAÇÃO GRATUITA:
- Crie uma conta no GitHub.
- Crie um repositório público e envie os arquivos.
- No Vercel, importe o repositório e publique.
- Use o endereço gratuito .vercel.app na bio do Instagram.

OBSERVAÇÃO:
Esta versão salva dados no navegador (localStorage). Para uso em um único computador/navegador, funciona sem banco e sem custo. Para acessar o painel de qualquer dispositivo e ter backup, será necessário adicionar um banco de dados posteriormente.
